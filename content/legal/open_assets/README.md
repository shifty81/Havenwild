# Havenwild Open Asset Credits

Havenwild uses a two-layer credit system.

## Broad master acknowledgment

`UNIVERSAL_LPC_MASTER_CONTRIBUTORS.txt` and `.csv` acknowledge every creator
attached to the commercially approved Universal LPC catalog available to
Havenwild development. This list may include creators whose approved assets do
not appear in a particular build.

## Exact release attribution

Every release must also generate `OPEN_ASSET_CREDITS.txt`, `.csv`, and `.json`
from the actual character recipes, generated composites, source overrides, and
other promoted open assets shipped in that build.

Broad acknowledgment does not replace exact attribution, license notices,
modification records, or ShareAlike obligations.
