# Havenwild Root Layout

Approved root files:

- `.gitignore`
- `Cargo.lock`
- `Cargo.toml`
- `README.md`
- `HavenwildTools.cmd`

`HavenwildTools.cmd` is the only human-facing launcher. Build implementation is under `tools/build/`, project control under `tools/control/`, and automation under `tools/automation/`.
