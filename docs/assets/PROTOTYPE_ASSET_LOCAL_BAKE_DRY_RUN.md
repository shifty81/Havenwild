# Prototype Asset Local Bake Dry-Run

Pass 23 adds a disabled-by-default local bake stub for donor/reference assets.

The goal is to let Havenwild learn from many external tileset sizes and asset families while keeping the project safe:

- donor packs stay quarantined or user-supplied
- blocked/non-commercial/unverified packs are refused by the bake gate
- no raw third-party files are copied into runtime folders
- no processed runtime atlas is generated by this pass
- the command writes a report only

## Dry-run command

```powershell
python tools/automation/assets/DryRun-PrototypeAssetBakeV29.py
```

The command checks each enabled prototype adapter against these source lookup areas:

```text
assets/reference_quarantine/third_party/<source>/
WORKSPACE/imports/
WORKSPACE/imports/third_party/
```

If a required source file is not present, the report records `missing_source`. That is expected in clean source control because raw donor archives should not be committed into public runtime folders.

## Blocked source behavior

A source is refused when its policy contains blocked, non-commercial-only, unverified, or license-chain-restoration language. Refused sources may still appear in the donor/reference asset browser for learning, cataloging, and future Lite Pixel Editor reference, but the bake path must not generate runtime assets from them.

## Why this is report-only

This pass establishes the safe command shape before any image processing exists. Later bake passes can add curated sheet extraction, 16→32 nearest-neighbor adapters, Tiled/Wang import adapters, and metadata emission. Those later passes must still keep:

- explicit user/source approval
- attribution metadata where required
- no standalone raw asset export
- runtime-default disabled until reviewed

## Generated report

The report is safe to commit because it records source availability and refusal status only. It does not contain image pixels or copied asset data.
