# Havenwild Pass 167Q — OGA LPC Cliff Normalization

This pass converts the Phase 1 cliff intake from loose source PNGs into a deterministic review catalog.

## Added

- Four 384×288 LPC-compatible cliff sheets retained under the selected CC-BY-SA 3.0 license.
- A generated 32×32 cell catalog covering 12 columns × 9 rows per sheet.
- Alpha occupancy and structural-empty detection for every source cell.
- A review contract for semantic roles, ramps, corners, repeatable faces, cave hosts, and waterfall overlays.
- A nearest-neighbor grid preview for visual classification.

## Production boundary

The cliff art is a visual binding library. Elevation and neighboring elevation remain the terrain source of truth. Cave entrances and waterfalls are overlay features attached to validated structural cliff faces.

## Next review

A human review pass must assign semantic roles to non-empty cells before runtime promotion. The editor should expose this catalog in Asset Browser and allow opening a selected cell in Pixel Studio through a Havenwild-owned override.
